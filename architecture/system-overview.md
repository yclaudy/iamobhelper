# System Overview

IaMob Helper was designed to centralize and automate commercial operations involving lead generation, qualification and CRM workflows.

The system architecture focuses on:
- conversational AI
- WhatsApp automation
- CRM integrations
- webhook orchestration
- operational scalability
- real-time data flow

---

# Main Operational Flow

```text
Traffic Sources
(Meta Ads / Google Ads)
        ↓
Landing Pages / Forms
        ↓
CRM Input Layer
        ↓
Webhook Processing
        ↓
IaMob Helper
        ↓
AI Qualification Engine
        ↓
Lead Categorization
(Qualified / Disengaged / Finalized)
        ↓
WhatsApp Automation
        ↓
Lead Routing
        ↓
Commercial Team
```
